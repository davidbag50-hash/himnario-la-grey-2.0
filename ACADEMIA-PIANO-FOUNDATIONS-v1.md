# Academia La Grey — Piano fundamentos v1

## Track ID

`piano-foundations-v1`

## Objetivo

Llevar a una persona que nunca ha tocado piano desde reconocer el teclado hasta poder preparar una parte sencilla y estable para una canción real del repertorio de su ministerio.

## Estructura

8 clases. Cada clase debe tener explicación breve, ejercicio, criterio de avance y aplicación práctica.

### 1. Conocer el teclado

ID: `piano-foundations-01-layout`

Objetivos:
- reconocer grupos de 2 y 3 teclas negras;
- localizar todos los Do;
- identificar Do–Re–Mi–Fa–Sol–La–Si;
- entender grave/agudo.

Práctica:
- localizar 5 Do distintos;
- tocar Do–Re–Mi–Fa–Sol con una mano;
- volver sin mirar etiquetas.

Listo para seguir:
- encuentra cualquier Do sin contar desde el extremo.

### 2. Postura y números de dedos

ID: `piano-foundations-02-posture-fingers`

Objetivos:
- sentarse a distancia cómoda;
- mantener hombros y muñecas sin tensión innecesaria;
- conocer dedos 1–5.

Práctica:
- patrón 1–2–3–4–5 y regreso;
- una nota por pulso a tempo lento.

Listo para seguir:
- puede repetir el patrón sin levantar tensión ni perder el pulso.

### 3. Primeros acordes mayores

ID: `piano-foundations-03-major-triads`

Objetivos:
- entender raíz–tercera–quinta;
- formar C, F y G;
- reconocer visualmente una tríada.

Práctica:
- C → F → G → C;
- 4 pulsos por acorde;
- después 2 pulsos.

Integración:
- reutilizar el visualizador de acordes de piano existente.

### 4. Acordes menores e inversiones

ID: `piano-foundations-04-minors-inversions`

Objetivos:
- formar Am, Em y Dm;
- entender inversión sin cambiar el nombre del acorde;
- reducir saltos entre acordes.

Práctica:
- C → G/B conceptual → Am → F;
- buscar posiciones cercanas;
- tocar progresión sin mover toda la mano innecesariamente.

### 5. Ritmo de acompañamiento

ID: `piano-foundations-05-accompaniment`

Objetivos:
- tocar acordes en bloque;
- separar bajo y acorde;
- sentir 4/4;
- introducir 6/8 sencillo.

Práctica:
- izquierda raíz, derecha acorde;
- 1 acorde por compás;
- después patrón bajo + acorde.

Criterio:
- mantener un minuto sin detener el pulso.

### 6. Leer una canción

ID: `piano-foundations-06-song-structure`

Objetivos:
- reconocer verso, coro, puente y final;
- seguir cifrado;
- anticipar el siguiente acorde;
- simplificar cuando sea necesario.

Práctica:
- escoger una progresión de 4 acordes;
- tocarla 8 vueltas sin parar;
- marcar dónde cambia cada sección.

### 7. Primera canción del ministerio

ID: `piano-foundations-07-ministry-song`

Objetivos:
- escoger una canción sencilla de `ministry_repertoire`;
- usar `official_tone`;
- abrir acordes existentes;
- preparar una versión sencilla completa.

Checklist:
- conozco estructura;
- conozco tono oficial;
- puedo tocar acordes base;
- sé dónde entrar y salir;
- anoté las secciones difíciles.

### 8. Preparación para ensayo

ID: `piano-foundations-08-rehearsal`

Objetivos:
- tocar sin detenerse por cada error;
- seguir al líder;
- dejar espacio a otros instrumentos;
- preparar preguntas concretas.

Proyecto final:
- una canción completa del repertorio;
- tonalidad oficial;
- parte simple pero estable;
- lista de 2–3 puntos para revisar en ensayo.

Finalización:
No significa “pianista avanzado”. Significa que el usuario tiene una base para entrar a un ensayo con una canción preparada.
